# 交前一查 · 比赛材料预检

给一份比赛通知，再选一个提交文件夹：程序从原文提取明确要求，列出能用文件证据确认的错误，把其余要求交给人。不会替你提交、修改作品或评判内容质量。

## Windows：一分钟看懂它

1. 下载发布附件 `jiaoqian-yicha-windows-x64.zip`（不是 GitHub 的 Source code），**完整解压到可写目录**，双击 `交前一查.exe`。无需安装 Python、Office、Ollama 或模型。程序未签名；若单位策略不允许运行，请交管理员审核。
2. 点右上角 **体验两赛对照**。程序用同一份 20 页 PPT、4 分 48 秒的视频和 Word 文档检查两次：创意展没有硬性错误，短片展报出 PPT 超页和视频超时。两个通知都是虚构示例。
3. 检查自己的材料：选通知 → 如有多个阶段，先选阶段 → 生成清单并核对原句 → 确认 → 选提交文件夹 → 开始预检。首页只列错误，**人工复核**里能看到未自动判定的原句。报告保存在本机 `通用版输出/`。

## AI 完全可选

默认只用规则。需要模型时，点 **模型连接 → 接入我的 AI**。DeepSeek 官方只需自己的 Key；其他兼容 Chat Completions 的接口填写基础地址（如 `https://你的服务/v1`）、模型 ID 和该服务的 Key。本机回环地址可用 HTTP，无鉴权的本机服务可不填 Key。

「测试连接并使用」只发固定测试文本。勾选 AI 识别并确认后才发候选通知段落（最多 9000 字，可能含整份通知）；复核只发你明确勾选的原句和检查类别，不上传作品。可能产生 API 费用。Key 仅本次运行有效，不写入报告。也可连接已有的本机 Ollama 9B 和配有纯聊天预设的 DSH；不是运行前提。

## 能查什么

查必交件、支持格式、大小、PPTX 页数和可读取的 MP4 时长。不可靠的 Word 分页、内容质量、字幕、匿名性或原创性留给人；「没有发现错误」不代表通过比赛审核。

## 从源码运行与测试

需要常规 CPython 3.10+，核心与离线测试只用标准库，无需 API Key。在仓库根目录运行：

```console
python -X utf8 run.py --demo
python -X utf8 -m unittest discover -q
```

Windows x64 可用 PowerShell 运行 `./desktop/build.ps1` 生成界面，然后运行 `./交前一查.exe`（源码模式需可发现的 Python）。`python package_windows.py` 会重编界面并生成便携 ZIP；首次打包从 python.org 下载并校验固定版本的嵌入运行时。包内第三方运行时许可见 `runtime/LICENSE.txt`。本仓库只含合成测试材料，不含真实参赛作品或历史复核记录。
